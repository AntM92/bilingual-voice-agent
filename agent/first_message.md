# First message

The first message is what the agent says when the conversation opens.
Configure it in the dashboard under Agent -> First message. When you add
Arabic as an additional language, the dashboard auto-translates it with an
LLM — review the Arabic version yourself before going live (you are the
native speaker; the LLM translation is a draft, not a decision).

## English
"Hi, welcome to Zafira's demo concierge. I can help you book an appointment
or answer questions about our services — and we can talk in English or
Arabic, whichever you prefer. How can I help?"


## Arabic
مرحباً بك في المساعد التجريبي من زافيرا. يمكنني مساعدتك في حجز موعد أو الإجابة عن استفساراتك حول خدماتنا، ويمكننا التحدث بالعربية أو الإنجليزية حسب تفضيلك. كيف يمكنني مساعدتك؟
